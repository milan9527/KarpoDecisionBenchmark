# 四张同型号 RTX 验证结果

用户选择的四张 RTX PRO 6000 Blackwell Server Edition 96GB 已完成独立验证。风控通过；SOP未通过。

原 Karpo 4B、完整 200 个风控特征、完整 200 个 SOP 候选保持不变。vLLM 0.34.0，FP8 按通道量化，每张 GPU 一个完整模型副本，最大序列数 4。

按资源快照 2026-11-20T14:58:00.411873+00:00 的 Spot 报价，四张 RTX 计算费用约 **7.90 美元/小时**。原 H100 按用户要求继续运行，未进入本轮代理；保留全部实例的计算费用约 **12.13 美元/小时**。不含磁盘、网络、公网 IPv4 等，Spot 报价可能变化。

本轮没有关闭任何 EC2。测量完成后压测驱动结束，模型服务仍保持运行；进程运行时限与 EC2 生命周期分开。生产外部入口和特征查询尚未纳入本次测试。
