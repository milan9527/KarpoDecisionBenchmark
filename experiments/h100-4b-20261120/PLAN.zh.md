# 单卡 H100 的 4B FP8 对照

RTX PRO 6000 上的 4B FP8 已测得约 123ms、98/104 参考一致。本次尝试在其他 AWS 区域获取单卡 H100，以判断相同模型能否因 GPU 架构改变而进一步提速。

只测试 `MachinePulseAI/karpo-decision-4B` 的 FP8 + CUDA Graphs，模型及代码 revision、全部 200 个候选、104 个质量请求、参考答案和候选顺序均与 RTX 实验相同。最大长度 8192，不截断，不进行程序候选筛选。

8 次预热、80 次原有观察、24 次边界观察，并发 1 / 2 / 4 / 8 各 24 次，共 208 次。单 GPU、同机 loopback HTTP、计时到完整响应。记录实际运行库版本、GPU、所有响应及失败。跨主机比较同时受到 CPU 和驱动等差异影响，不能归因为单一硬件参数。

本次输入已在 RTX 上测试过，属于性能对照，不是新的独立质量验证。AWS 容量失败单列，不能当作模型延迟数据。实例结束后只 stop，不 terminate，保留 EBS 和模型。
