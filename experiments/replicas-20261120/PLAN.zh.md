# 官方单副本与双副本对照

在 g7e.12xlarge 的两张 RTX PRO 6000 Blackwell 上验证官方 HTTP 服务的副本扩展。仍然完整传入 200 个英文精简候选，由模型一次选择，不进行业务域判断或候选过滤。

在系列模型实验结束后，从已完成的 FP8 配置中选取本批 104 次质量观察全部有效、且相对同机 31B 没有新增错误的最快配置。选择依据为合并质量观察的 P50；这属于本批数据上的部署候选选择，不能作为独立泛化验证。选择规则在系列实验结果产生前冻结。

依次启动 `--nproc_per_node 1` 与 `--nproc_per_node 2`，其余配置和模型版本保持一致。官方多进程模式是每张 GPU 各加载一份完整模型，按正在处理的请求数分发，不是把单次推理拆给两张 GPU。

每次启动先做 8 次预热，再对同一批 52 个合成案例的两种候选顺序做 104 次质量观察，最后进行并发 1 / 2 / 4 / 8 / 16 扫描，每格 32 次。共计划 544 次调用，包括预热及重复请求。客户端与服务同机，计时到读取完整 HTTP 响应，错误计入尝试分母。

保留所有响应、无效请求、服务日志和 GPU 监控。结果比较参考一致性、P50 / P95 和有效请求吞吐，不能从短时扫描声称持续高并发 SLA。服务退出后同步结果并 stop 实例，不 terminate，模型和系统盘保留。
